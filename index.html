Verified public camera catalog
Using these in Ignition

Perspective: add a Video Player component, set props.source to the HLS (.m3u8) URL. Use Copy Perspective binding below for an expression-ready value.

Vision: MJPEG/JPEG work in an Image component (or a Label with an HTML <img>) via a URL path; for snapshots, refresh with a timer script:

img = system.net.httpGet("SNAPSHOT_URL")  # bytes
# or set the component's image path to the URL and toggle it on a timer

RTSP cameras can't play in a browser; convert to HLS with FFmpeg or go2rtc on the gateway machine.

CORS: if a preview fails here but plays in VLC, the camera server blocks browser embedding. Ignition's Video Player may still work (it loads from the client), or relay it through your gateway/go2rtc.

Only use cameras that are intentionally public, and respect each provider's terms.
